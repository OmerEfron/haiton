## 1. Bugs

### Full reload of `/profile` serves JSON

Typing or refreshing `http://localhost:5174/profile` returns the API JSON payload (Chrome “Pretty-print” view) instead of the SPA.

Vite proxies `/profile` to the API. Production `frontend/worker.ts` already keeps document navigations on HTML; `frontend/vite.config.ts` does not. Client-side clicks still work.

**Fix:** Same bypass as the worker — if the request is a document navigation to `/profile`, serve the SPA.

### Draft counter is wrong

Profile **טיוטה בעריכה** showed **1** on an empty account, and still **1** after a successful publish.

```ts
interview.data?.draft.status !== "empty" ? 1 : p.stats.draftsInProgress
```

`undefined !== "empty"` is `true`, so the count is 1 while the interview query is loading (and can stay stale after publish).

**Fix:** Treat missing session as 0: `interview.data?.draft.status && interview.data.draft.status !== "empty"`.

### Story byline date

Published story showed `, 12:39` — comma and time, no date.

### Reporter used the wrong name

Account name was **בודק העתקה**. Tester saved the karteset example chip **“עומר, 29, חיפה”**. The reporter then asked *“עומר, מה בדיוק קרה…”*.

Example facts are ingested as identity. Do not treat starter chips as the user’s name, or label them clearly as examples and do not auto-save them into the karteset used by the reporter.

### Two profile links both look current

Desktop nav **ניהול המעגל** and **כתב הבית** both point at `/profile`, so both highlight as active.

### “נסחו טיוטה” is covered

The disabled banner **“אין טיוטה עדיין — כשתרצו ידיעה, בקשו מהכתב לנסח”** sits on top of the real draft button. First click was intercepted (`Click target intercepted`). User must scroll to reach it.

### Login error is misleading

Wrong email/password returned **“צריך דוא״ל וסיסמה כדי להיכנס”** even though both fields were filled. That error also stayed visible after switching to the **הרשמה** tab.

### Interview type/tone chips overlap

On the first chat layout, **טון** chips crushed into each other. After scroll they were readable. Layout collision on a phone-width viewport, not a missing control.

### Mobile bottom nav can have zero size

On `/u/:id`, **המעגל** in the mobile bar reported zero dimensions (unclickable). Footer link still worked.

## 4. Inconvenient flows

**Onboarding is a blank newspaper.** After signup: “המהדורה הראשונה שלך עוד לא נכתבה” and one button. No hint to fill karteset, invite someone, or what a מהדורה is.

**Karteset examples are someone else’s bio.** “עומר, 29, חיפה / עובד בפיתוח תוכנה / בן זוג ושותפה לדירה” looks like real data. Clicking fills the field; saving poisons the reporter.

**Interview chrome eats the screen.** Type (6) + tone (6) + composer + draft panel + empty-draft banner. After draft, chat is locked (“הכתב סיים לשאול”) so you cannot correct a fact in conversation — only **התחילו מחדש** or manual edit.

**Draft is slow**, and the UI contradicts itself: “הכתב מנסח טיוטה…” next to “אין טיוטה עדיין”.

**Circle is buried.** Invite copy sits under the sticky bottom nav until you scroll. No add-by-email, no QR.

**Same page, three names:** **המעגל** / **ניהול המעגל** / **כתב הבית** all go to `/profile`.

**Duplicate nav:** top bar (ראשי / מבזקים) + bottom bar + footer + desktop masthead.

**Cannot discard a draft from the homepage.** Only “המשך לטיוטה”. Restart lives inside the interview room.

**Signup inherits the failed login** — email, password, and the login error carry over onto **הרשמה**.

## 5. Too much text

- **Published article:** two sentences of input became five paragraphs of “לא נמסר / לא זוהה / אם תימסר התייחסות נוספת…”. Reads like a wire story about missing facts, not a personal paper.
- **Briefs empty state** says the same thing twice: “אין מבזקים במהדורה הזו” and “לא נמצאו מבזקים כרגע”.
- **Interview empty draft** repeats the same sentence twice (composer + overlay).
- **User edition** after one story still shows empty headings **עוד במהדורה**, **מבזקים**, **כל הידיעות**.
- Circle intro on an empty panel is a long newspaper metaphor.
- Editorial voice on buttons (**שמרו / התחילו / רשמו**) is consistent but feels like an order.

## 6. Missing features a common user would look for

**Basic**

- Edit or delete a **published** story (only karteset facts have עריכה / הסרה).
- Unpublish / hide from the front page.
- Profile photo (letter avatar only).
- Change email or password; forgot-password.
- Delete account.
- Age in the edit dialog (profile can display age; dialog has name / city / headline only).
- Notifications when someone accepts an invite.
- Search, comments, reactions.
- Images / audio in the interview.
- “Continue later” that feels saved (toast on **שמרו כטיוטה**).

**This product**

- Invite by phone/email, not only `/join/:token`.
- Clear “my edition” vs “a friend’s edition” (byline is always “כתב העיתון | שולחן העורכים”).
- Privacy: circle-only vs public `/s/…` share link.
- Stop the reporter using karteset examples as the user’s name.
- Shorter drafts, or a מבזק that stays a one-liner.
- Onboarding: name → 3 karteset facts → invite one person → first interview.
- Interview history that is not a single archive row mixed with stories.

## Recommendations (priority)

1. **Local `/profile` proxy** — document navigations must serve the SPA. Same rule as `frontend/worker.ts`.
2. **Draft counter** — do not treat `undefined` as a live draft; invalidate after publish.
3. **Byline date** — stop rendering a leading comma when the date part is empty.
4. **Karteset examples** — generic placeholders, or do not persist chips into the reporter’s identity facts.
5. **Interview overlay** — remove the disabled “אין טיוטה עדיין” button; one line of helper text is enough. Make **נסחו טיוטה** actually clickable.
6. **Auth errors** — “wrong email or password” on failed login; clear the error when switching to signup.
7. **Nav naming** — one label for profile. Do not highlight both **המעגל** and **כתב הבית**. Soften the always-red **ראיון** tab so it only looks selected on `/interview`.
8. **Published stories** — edit, delete, and a visible save confirmation for drafts. Without these the paper feels write-once.
9. **Draft length** — cap padding / “facts not provided” paragraphs. A two-sentence interview should not become five grafs.
10. **Onboarding** — after signup, one short path: karteset → invite → first interview. Empty newspaper + one button is not enough.
